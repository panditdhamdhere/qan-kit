- solc dropped `solc-build-cache/` in the repo root during the local ABI compile. It is gitignored now.
- 2026-11-27 later: XLINK address `0xFed578b7Acb4D353440a067bed3b18404E59d4D0` had 10 QANX and was linked. Two deploys mined because a retry ran after qvmctl had already broadcast. qvmctl then timed out waiting for the receipt and exited 1, so `qan` did not save the file. - 2026-11-28: `qan call Counter count` on the first contract returned `0`. The CLI then crashed printing the bigint (`Do not know how to serialize a BigInt`). `JSON.stringify` now writes uint256 values as decimal strings.

The task now `import()`s core, and the network defaults are literals checked against `@qan-kit/chains` in the test. It also reads `.env` the way the CLI does.
